Download and install

GeoTag Camera is free. Right now it installs from a signed APK on GitHub; F-Droid and Google Play are coming soon. Here's which file to pick, how to check it, and how to install it.

Coming from 1.3.0 or older? Uninstall the old version first. Those builds were signed with a development key, and 1.4.0 uses the project's new permanent key, so Android can't update in place. Photos in your gallery stay where they are and still verify. After installing, Gallery, Import photos re-adds them to the in-app list. From 1.4.0 on, updates install over the top as usual.

Get it from

The signed APK on GitHub is available now. F-Droid is reviewing the submission and the Google Play release is being prepared; their badges light up here once they're live. Because the builds are reproducible, the F-Droid APK will carry the same signature as the GitHub one, so you can switch between them without reinstalling. GeoTag Camera is published only on GitHub, F-Droid and Google Play: an APK from anywhere else is not from this project.

Which APK do I need?

Each release has one APK per processor type plus a universal one. If you're not sure, take arm64-v8a: nearly every Android phone from the last several years uses it. If it refuses to install, use the universal APK, which works everywhere but is bigger.

Check the download (optional)

Every APK has a matching .sha256 file. Download both into the same folder and compare. If the values differ, delete the APK and download it again.

Windows (PowerShell)

Get-FileHash .\geotagcamera-v{{version}}-arm64-v8a.apk -Algorithm SHA256
Get-Content .\geotagcamera-v{{version}}-arm64-v8a.apk.sha256

The two hex values must match (case doesn't matter). In Command Prompt, certutil -hashfile geotagcamera-v{{version}}-arm64-v8a.apk SHA256 does the same.

macOS

shasum -a 256 -c geotagcamera-v{{version}}-arm64-v8a.apk.sha256

Linux

sha256sum -c geotagcamera-v{{version}}-arm64-v8a.apk.sha256

Both print OK when the file is intact.

Install

  1. Download the APK on your phone, or copy it over from your computer.
  2. Open it from your browser's downloads or your file manager.
  3. The first time, Android asks you to allow installs from that app. Allow it for that app only, then go back and tap Install.
  4. Open GeoTag Camera, pick Field or Professional, and allow camera and location when asked.
  5. Wait for "Location locked" in the corner of the viewfinder, then take your first photo.

Play Protect may warn about an app it hasn't seen before. That's expected for apps installed outside the Play Store. The source is public, and you can compare the file with its SHA-256 above.

Updating

From 1.4.0 on, every release is signed with the same key, so a newer APK installs over the old one and keeps your photos, projects and settings. Download it the same way and open it.

  • GitHub: on the repository, choose Watch, Custom, Releases to get an email when a new version is out.
  • Once the F-Droid listing is live, the F-Droid app will handle updates too, and it installs over a GitHub APK. The Google Play version is a separate listing with its own updates.

System requirements

  • Android 8.0 or newerAPI level 26 and up, phones and tablets.
  • Camera and GPSLocation must be switched on. Approximate-only location still works, with less precise stamps.
  • No Google Play servicesWorks on de-Googled phones. Address lookup needs a geocoder on the phone, otherwise the stamp shows the Plus Code.
  • Internet optionalOnly for the stamp map, offline map downloads and the optional weather chip.
  • StorageAbout 15 MB for the app, plus up to about 150 MB of map cache and any offline areas you save.
  • PermissionsCamera, location while the camera is open, photo location (for Verify), and storage on Android 9 and older only.
