# GeoTag Camera website

Static site for https://konkomaji.com/geotagcamera/ (Hostinger, Apache/LiteSpeed). No third-party
requests, no analytics, no cookies. All internal links are relative, so the folder works under
`/geotagcamera/` and locally.

## Layout

| Path | What it is |
|---|---|
| `build.py` | Builds, checks and zips the site. Python 3.9+, standard library only |
| `pages/` | Hand-written page bodies (home, download, support, 404). `{{root}}`, `{{home}}`, `{{version}}`, `{{stores}}`, `{{faq}}`, `{{screens}}`, `{{dl}}`, `{{mailto}}` are filled in by build.py |
| `assets/site.css`, `assets/site.js` | Styles and the small script (theme toggle, menu, store badges) |
| `assets/site.js` `STORES` | Which store badges are live. Set `"live": true` for F-Droid or Google Play once listed, then rebuild |
| `assets/fonts/` | Poppins and Roboto Mono, copied from `app/src/main/res/font/` (OFL 1.1) |
| `assets/badges/` | Official store badges; sources and licences in its README |
| `assets/screens/1.png`..`6.png` | App screenshots (captions in `SCREENS` in build.py) |
| `assets/icons/`, `assets/og-image.png` | Generated by `tools/make_assets.py` (needs Pillow; only rerun when the icon changes) |
| `static/` | `.htaccess`, `robots.txt`, `llms.txt`, `site.webmanifest`, copied to the site root |

Generated on every build, so they never drift from the repo: privacy (`PRIVACY.md`), terms
(`TERMS.md`), licences (`THIRD_PARTY_NOTICES.md` + `LICENSE` + `LICENSES/*.txt`) and changelog
(`CHANGELOG.md`). The version number comes from `versionName` in `app/build.gradle.kts`; the FAQ
(and its FAQPage JSON-LD) from the `FAQ` list in build.py.

## Build

```
python site/build.py
```

Writes `site/dist/geotagcamera/`, `site/dist/geotagcamera-site.zip` and `site/dist/github-pages/`.
The build fails (and writes no zip) on a broken relative link or anchor, invalid JSON-LD, a page
without title/description/canonical, inline styles or scripts (blocked by the CSP), external
resources, or emoji. Missing screenshots are only a warning.

Preview locally: `cd site/dist && python -m http.server 8000`, then open
http://localhost:8000/geotagcamera/.

## Upload to Hostinger

1. Run `python site/build.py`.
2. hPanel, Files, File Manager, open `public_html/`. Create the folder `geotagcamera` if it doesn't exist.
3. Open `public_html/geotagcamera/`, upload `site/dist/geotagcamera-site.zip`, right-click it, Extract, into
   the current folder (the zip has no top folder, so files land directly in `geotagcamera/`). Delete the zip afterwards.
4. Check that `.htaccess` is there (File Manager, Settings, show hidden files).
5. Open https://konkomaji.com/geotagcamera/ and https://konkomaji.com/geotagcamera/nothing (should show the 404 page).

FTP instead: connect with the FTP account from hPanel (Files, FTP Accounts) and upload the
contents of `site/dist/geotagcamera/` (including the hidden `.htaccess`) into `public_html/geotagcamera/`.

## Update

Edit the source (or the repo markdown for legal pages and changelog), run `python site/build.py`,
and upload the new zip the same way, overwriting files. To remove pages that no longer exist,
delete the old `geotagcamera/` contents first. CSS and JS carry a content hash in their URL, so
browsers pick up changes straight away despite the one-year cache.

## Domain root (outside this folder)

- Crawlers only read `robots.txt` at the host root. Add this line to `https://konkomaji.com/robots.txt`:
  `Sitemap: https://konkomaji.com/geotagcamera/sitemap.xml`
- HSTS is commented out in `.htaccess` because it would apply to the whole domain. Turn it on at the
  root once all of konkomaji.com is HTTPS-only.
- Optionally register the sitemap in Google Search Console and Bing Webmaster Tools.

## GitHub Pages

`.github/workflows/deploy-pages.yml` runs `build.py --no-zip` and publishes only
`dist/github-pages/`: an `index.html` and `404.html` that redirect
`konkomaji.github.io/geotagcamera/<path>` to `konkomaji.com/geotagcamera/<path>` (JavaScript, with a
meta refresh and a canonical link as fallback).
